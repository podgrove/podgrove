# Podgrove identity

The **Pods** mark is Podgrove's approved logo. Two separated forms create a lowercase `p`, reflecting independent worktree environments. The symbol is drawn as SVG and stays legible at small sizes.

| Asset | Use |
| --- | --- |
| [Adaptive logo](assets/logo.svg) | README, favicon and backgrounds following the system light/dark preference. |
| [Light theme](assets/logo-light.svg) | Terracotta mark on a light neutral background. |
| [Dark theme](assets/logo-dark.svg) | Warm light mark on a dark neutral background. |

The dashboard uses the same geometry with its existing theme accent. Keep its aspect ratio and leave clear space around it. Use `Podgrove` in prose and `podgrove` for the executable. These are visual consistency guidelines; do not imply that a modified distribution is an official release.
